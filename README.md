# ECB IT Helpdesk & Asset Management Portal
بوابة إدارة أصول تكنولوجيا المعلومات، الدعم الفني، وتتبع العهد الميدانية لمشاريع شركة ECB للاستشارات الهندسية.

## المميزات:
- إدارة وتعديل كامل الأصول: الرقم التسلسلي (S/N)، الموديل، نوع الجهاز، المواصفات التقنية، والمشروع التابع له.
- سجل حركات ومناقلات الأجهزة والمشاريع مع إمكانية التعديل السريع.
- توليد محاضر العهدة ونماذج إخطار الصيانة للمقاولين جاهزة للطباعة (A4).
- توليد وطباعة ملصقات QR Code الحقيقية لكل أصل.
- نظام مستقل بالكامل (Standalone) يعمل داخل المتصفح مباشرة دون الحاجة لخادم أو قواعد بيانات خارجية.

## طريقة الرفع والتشغيل على GitHub:
1. أنشئ مستودعاً جديداً (Repository) على حسابك في GitHub.
2. ارفع محتويات هذا المجلد مباشرة.
3. لتفعيل الرابط المباشر المجاني عبر GitHub Pages:
   - اذهب إلى **Settings** > **Pages**
   - اختر الفرع `main` ثم مجلد `/ (root)` واضغط **Save**.
